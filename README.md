# E-Commerce Django Project

A full-featured E-Commerce web application built using Python and Django framework with AI recommendations.

## Features
- **Accounts:** User authentication and profile management.
- **Products & Cart:** Browse products, add items to cart, and manage orders.
- **AI Recommendation:** Integrated recommendation system for smart product suggestions.
- **Database:** SQLite.
